# KQ GAMES — nowa strona

To jest nowy portal KQ GAMES. Nie zawiera kodów właściwych gier — tylko stronę główną, katalog i puste miejsca na Twoje gry.

## Gry i foldery

- KQ RACING → `games/kq-racing/index.html`
- KQ CRAFT → `games/kq-craft/index.html`
- KQ CLICKER → `games/kq-clicker/index.html`
- KQ CITY → `games/kq-city/index.html`

W każdym folderze jest plik `index.html` z prostą stroną-placeholder. Możesz go całkowicie zastąpić własnym kodem gry. Nie zmieniaj nazw folderów, bo od nich zależą przyciski na stronie głównej.

## Publikacja na GitHub Pages

1. Rozpakuj ZIP.
2. Wgraj całą zawartość folderu `KQ_GAMES_OD_NOWA` do głównego katalogu nowego repozytorium.
3. Wejdź w Settings → Pages.
4. Wybierz Deploy from a branch, gałąź `main` i folder `/ (root)`, a następnie Save.

Strona główna to `index.html`.
